# M1.2 - Validacion de metricas en Windows y Linux

## Objetivo

Se ejecuto el mismo archivo cliente/metricas.py en Windows y Linux sin modificar su codigo fuente.

- Libre: 135.12 GB
- Uso: 85.38 %
- IOPS lectura: 145
- IOPS escritura: 70

## Linux

- Nombre: /
- Tipo: HDD
- Total: 24.44 GB
- Usado: 11.54 GB
- Libre: 11.63 GB
- Uso: 47.24 %
- IOPS lectura: 0
- IOPS escritura: 0
- Latencia: 0.0 ms

## Diferencias entre sistemas

Windows utiliza rutas de unidades como C:\ mientras que Linux utiliza puntos de montaje como /.

La ejecucion de Linux se realizo dentro de una maquina virtual de VirtualBox. Por eso las caracteristicas del almacenamiento corresponden al disco virtual asignado a la maquina virtual y no directamente al SSD fisico del equipo.

Los valores de IOPS y latencia tambien presentan diferencias debido a la forma en que cada sistema operativo y el entorno virtualizado exponen las metricas de almacenamiento.

## Resultado

El mismo archivo cliente/metricas.py pudo ejecutarse en ambos sistemas sin modificar su codigo fuente. Las diferencias observadas corresponden al sistema operativo y al entorno de almacenamiento utilizado.
